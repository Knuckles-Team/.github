Core projects

Seven core projects. Arbora is the governed runtime gateway. It hosts Overstory and delegates agent work to Meristem; Epistemic Graph owns durable knowledge, and Scion SDK governs source integration; Tuig and Axil are operator surfaces on the same boundary.

  • Arbora — runtime and gateway.
  • Epistemic Graph — durable knowledge and reasoning; publishes epistemic-graph and epistemic-graph-server (the native server and its container image).
  • Scion SDK — governed connector contracts.
  • Meristem — agent orchestration.
  • Overstory — browser experience.
  • Tuig — terminal operator surface for the Arbora REST interface.
  • Axil — desktop GUI.
