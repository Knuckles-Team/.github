universal-skills distributes the shared contributor skills. The Graph OS package contains the canonical ecosystem development skill and its public bootstrap recipe. The universal-skills entry makes that canonical skill discoverable before Graph OS is installed.

Install the skill kit with pip install universal-skills and install-skills --all-detected --symlink. Read a chosen repository's AGENTS.md and all five owner spec files before building: spec.md, plan.md, test-spec.md, tasks.md, and status.json. The contribution guide gives the full path from a public checkout to a PR.

Where the code lives

The organization hub owns the cross-repository map, status report, and governance. Each deliverable is implemented in the repository named by its owner spec. Related specs describe consumers and interfaces; a disputed owner stays unresolved until its contract is reviewed.

Five core projects

Graph OS is the governed runtime gateway. It hosts Agent Web UI and delegates agent work to Agent Utilities; Epistemic Graph owns durable knowledge, and Agent Connector SDK governs source integration.

  • Graph OS — runtime and gateway.
  • Agent Web UI — browser experience.
  • Agent Utilities — agent orchestration.
  • Epistemic Graph — durable knowledge and reasoning.
  • Agent Connector SDK — governed connector contracts.

Additional operator surfaces

Agent Terminal UI and GeniusBot use the same Graph OS boundary and are outside the five core projects.

  • Agent Terminal UI — terminal operator surface for the Graph OS REST interface.
  • GeniusBot — desktop cockpit.

Related contributor repositories

Repository Manager owns workspace lifecycle; Pipelines owns shared CI and release workflows; Emerald Exchange owns exchange integration; Tunnel Manager owns tunnel lifecycle; and Universal Skills provides shared contributor skills.
