# Organization-owned specifications

The organization repository owns cross-repository governance contracts. Runtime,
engine, connector, UI, and workspace implementation specs remain in their owner
repositories. See the [public specification status](../site/spec-status.html)
and [build-first program](../site/build-first.html).

Every spec here provides `spec.md`, `plan.md`, `tasks.md`, `test-spec.md`, and
`status.json`. A cross-repository governance spec can set rules and track
owner-native receipts; it cannot declare a component accepted on its own.
